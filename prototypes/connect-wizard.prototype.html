Connect Wizard Prototype

The question this page answers: does a connect wizard that runs entirely inside VS Code feel right? VS Code runs as glitch and the Claude session runs as claudebwai. The wizard reaches the other account through sudo, so nobody opens a second terminal. You pick the host's conditions below, then click through. Rule of thumb: nothing changes on disk until you press Connect, and anything that fails afterwards is undone.

Throwaway prototype, 24 Sep 2026. Nothing here touches a real machine. The paths and the process ID are from this morning's attempt.
